# Изображения для лендинга

Разместите PNG изображения в следующих папках:

## Структура папок

```
public/
  images/
    features/
      interactive.png  - Иконка для интерактивных уроков
      progress.png     - Иконка для отслеживания прогресса
      community.png    - Иконка для сообщества
      mobile.png       - Иконка для мобильного приложения
    
    medals/
      gold.png         - Золотая медаль (1 место)
      silver.png       - Серебряная медаль (2 место)
      bronze.png       - Бронзовая медаль (3 место)
      fourth.png       - Иконка для 4 места
      fifth.png        - Иконка для 5 места
    
    courses/
      beginner.png     - Иконка для начального курса
      intermediate.png - Иконка для среднего курса
      advanced.png     - Иконка для продвинутого курса
      business.png     - Иконка для делового курса
    
    stats/
      students.png     - Иконка для статистики студентов
      lessons.png      - Иконка для статистики уроков
      teachers.png     - Иконка для статистики преподавателей
      countries.png    - Иконка для статистики стран
```

## Рекомендации

- Размер иконок: 64x64px или 128x128px
- Размер медалей: 64x64px
- Формат: PNG с прозрачным фоном
- Оптимизация: Используйте сжатые PNG файлы для лучшей производительности
